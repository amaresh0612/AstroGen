# Review Astro Report Quality

## Process

1. Identify report tier (concise / standard / professional)  
2. Check factual grounding against chart payload fields  
3. Check KP method order (CSL → significators → dasha)  
4. Check safety language  
5. Check structure/completeness  
6. Return findings as Critical / Suggestion / Nice-to-have  

## Rubric

| Score | Meaning |
|-------|---------|
| A | Client-ready professional |
| B | Solid; minor gaps |
| C | Generic or under-cited |
| F | Invented data or unsafe claims |

## Feedback format

- Critical: wrong lord/date, invented planets, unsafe claims  
- Suggestion: weak citations, missing timing, uneven sections  
- Nice-to-have: typography, appendix tables, transit color
